## Short description (paste into Gumroad)
A bold, fully animated restaurant website you can rebrand in minutes. Change the name, colours,
fonts, menu, prices, contact details and photos in **one config file**. No design or animation
work needed.

**Live demo:** [PUBLIC DEMO URL]

**What you get**
- Complete source code (React 19, Vite, TypeScript, GSAP, Motion, Lenis)
- 11 cinematic, mobile-first sections: hero slider, scroll animations, menu with tabs, gallery,
  reviews, contact and more
- One typed config file for branding, menu, prices, hours, links and socials, checked before every
  build so mistakes don't go live
- Brand colours and fonts in one place
- Working email, phone, Google Maps, social and reservation buttons
- A demo cart and checkout that never sends orders or takes payments
- Optional order and Stripe server code for developers, if the restaurant wants it later
- Step-by-step install, customisation, deployment and handover guides
- 69 automated tests and a secret-key scanner

**Not included**
- Real online ordering, payment (Stripe), POS or delivery-platform integration. The code
  includes optional starting points, but setting them up is not part of this purchase.
- Hosting, a domain, ongoing maintenance or support beyond the included guides.
- Photos. The template ships with original placeholder images. Use the restaurant's own photos.
  (The photos in the live demo are not included.)

**Licence:** one website for one client per purchase. You can modify it freely and hand the
finished site to your client. You may not resell or redistribute the template. Full terms are in
`LICENSE.md`.

**Requirements:** Node.js 20.19+ and basic comfort running commands in a terminal.

## Basic deployment add-on (+$10 CAD): exact scope
Included:
- One deployment of the **unchanged demo, or a config the buyer has already completed**, as a
  static site on the buyer's own free Cloudflare Pages (or Netlify) account.
- The buyer creates the account and gives temporary access, or deploys on a screen-share.
- One free `*.pages.dev` / `*.netlify.app` address.

Not included: content editing, custom domain purchase or DNS, ordering, payments, POS, email set-up,
or changes after delivery.

## Installation instructions (paste into the Gumroad "content" page)
1. Download and unzip the file.
2. Install Node.js LTS from nodejs.org.
3. Open a terminal in the unzipped folder and run `npm install`, then `npm run dev`.
4. Open http://localhost:5173 to see the demo.
5. Follow `INSTALL.md` to create your restaurant's config, add photos, build and publish.
