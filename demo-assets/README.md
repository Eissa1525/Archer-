# demo-assets (internal, NOT in the sold package)

- `public/`: the Unsplash photos and credits page used only for the public showcase demo.
- `showcase.config.ts`: the demo config plus the Unsplash credits line.

Build the showcase (identical to the original Fire Alley demo):

```bash
SITE_CONFIG=demo-assets/showcase.config.ts PUBLIC_DIR=demo-assets/public npm run build
```

Excluded from `npm run package` via `.gitattributes`. The sold package ships the original
placeholder images in `public/img/` (generated by `scripts/make-placeholders.py`).
